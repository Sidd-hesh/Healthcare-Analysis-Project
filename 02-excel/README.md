## 🎯 Key Formulas to Learn

### Basic Functions
- `SUM()` - Add numbers
- `AVERAGE()` - Calculate average
- `COUNT()` - Count cells
- `MIN()` / `MAX()` - Minimum/Maximum
- `IF()` - Conditional logic
- `VLOOKUP()` - Find data

### Examples

```excel
=SUM(A1:A10)              # Add cells A1 through A10
=AVERAGE(B1:B20)          # Average of B1:B20
=IF(A1>30,"Old","Young")  # IF condition
=COUNTIF(A:A,"Yes")       # Count cells with "Yes"
```

## 💡 Best Practices

1. **Use headers** - First row should label your data
2. **Keep data clean** - No empty rows/columns in data
3. **Use meaningful names** - Name your ranges and sheets
4. **Document formulas** - Add comments to complex formulas
5. **Backup frequently** - Save as you go!

## 🚀 Getting Started

1. **Open a blank spreadsheet** (Excel, Google Sheets, or LibreOffice)
2. **Create sample data** - Copy data from `datasets/`
3. **Follow tutorials** - Start with `01-basics/`
4. **Practice formulas** - Try in `02-formulas/`
5. **Analyze data** - Use techniques from `03-data-analysis/`

## 📖 Common Questions

**Q: Excel vs Google Sheets?**
A: Both work! Google Sheets is free and cloud-based, Excel is more powerful. Learn on either!

**Q: How do I share an Excel file?**
A: Save as .xlsx (Excel format) or .csv (plain text, compatible with Python/SQL)

**Q: Can I connect Excel to SQL?**
A: Yes! You can query databases directly in Excel (advanced topic)
